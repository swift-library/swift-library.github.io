Contributing code

Start in the repository that owns the behavior you want to change. Read its README and contribution guide, keep the change focused, and run that repository's validation commands before opening a pull request.

For a bug report, include the package version, Swift version, platform, and a small example that reproduces the problem. Describe what you expected and what happened.

Versioning and releases

Packages release independently with vMAJOR.MINOR.PATCH tags. During 0.x, breaking changes raise the minor version and compatible changes raise the patch version. Published tags are immutable.
